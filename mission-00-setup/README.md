```bash

git --version

```

Record the actual Python and Git version strings locally. Before sharing command output, remove personal usernames, device names, and private paths. The repository is the project folder plus its Git history and metadata. Mission folders keep work organised by topic and make progress easier to review.

## 5. My understanding
A repository stores project files together with their change history. Git records changes as commits, while GitHub hosts a remote copy so work can be backed up and shared. A clear folder structure makes it easier to find each mission and review its work independently.
